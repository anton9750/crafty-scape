# Audio assets

Put your files here (names can be changed in `src/config/audio.ts`):

- `music/background.mp3`  – looping background music
- `sounds/drag-01.mp3` … `sounds/drag-10.mp3` – 10 drag sounds, played in random order

Missing files automatically fall back to built-in synthesized sounds.
Keep drag sounds short (under ~1 second) for a snappy feel.
